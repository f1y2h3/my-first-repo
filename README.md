# my-first-repo

我的第一个 GitHub 仓库，用来练习 Git 的基本操作。

## 这个仓库是干嘛的

纯练手。目标是把我电脑上的文件夹，原封不动地传到 GitHub 上，并且以后能持续更新。

## 我已经学会的几条

| 命令 | 大白话 |
|---|---|
| `git init` | 让 Git 开始看住这个文件夹 |
| `git add .` | 把改动放进待提交的筐里 |
| `git commit -m "说明"` | 拍一张快照，写清楚这次改了什么 |
| `git push` | 把快照送到 GitHub 上 |
| `git status` | 看看现在有哪些改动还没提交 |

## 更新流程（以后每次改完代码）

```
git add .
git commit -m "这次改了什么"
git push
```

就这么三步。
